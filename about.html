IGNOU BCA Course Management System

This website is a final year BCA project built to help IGNOU students easily access their study resources. It offers a centralized platform for semester-wise access to study materials, YouTube lectures, assignments, and previous year question papers.

Key Objectives

  • Provide a digital library of IGNOU BCA books and materials.
  • Organize YouTube lectures course-wise for each semester.
  • Help students access assignments and PYQs in one place.
  • Make the interface simple, fast, and responsive for all users.

Technology Stack

  • Frontend: HTML, CSS, Bootstrap
  • Backend: PHP, MySQL
  • Platform: Designed to run locally or host on any web server
